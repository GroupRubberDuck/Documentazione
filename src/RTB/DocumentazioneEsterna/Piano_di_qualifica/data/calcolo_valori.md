
- `PV = somma (ore_stimate * costo_orario_del_ruolo)`: lavoro teoricamente completato
- `EV = somma (min(ore_stimate, ore_lavorate) * costo_orario_del_ruolo)`: lavoro effettivamente completato
- `AC = somma (ore_lavorate * costo_orario_del_ruolo)`: lavoro effettivamente impiegato
- `BAC`: valore totale pianificato
- `CPI = EV / AC`: Cost Performance Index
- `ETC = (BAC - EV) / CPI`: quanto budget aggiuntivo serve per completare il lavoro
- `EAC - BAC / CPI`: Estimated At Completion
